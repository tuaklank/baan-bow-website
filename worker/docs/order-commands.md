# คำสั่งออเดอร์โบว์ทางไลน์

คำสั่งในหน้านี้เป็นแพตเทิร์นตายตัว บอทอ่านจากข้อความตรงๆ ไม่ผ่าน AI
ผลจึงเหมือนเดิมทุกครั้งและไม่เสียโทเค็น ตัวอ่านอยู่ที่ `src/order-text.js`
พิมพ์ `วิธีสั่งออเดอร์` ในไลน์เพื่อดูฉบับย่อ

ข้อความที่ไม่เข้าแพตเทิร์น (เช่น `ออเดอร์ 3 สีแดงทอง`) ยังส่งต่อให้ AI อ่านตามเดิม
แต่ AI อาจเดาช่องผิด จึงควรใช้แพตเทิร์นด้านล่าง

## จดใหม่ (ผ่าน AI)

| พิมพ์ | ผล |
|---|---|
| `สั่งโบว์ ML แดงทอง 10 ชิ้น` | ได้ 10 แถว ช่องทางและผู้สั่งว่างไว้ |
| `สั่งโบว์ ML 10 ชิ้น mini 5 ชิ้น` | หลายแบบในข้อความเดียว |

## แก้ไข

รูปแบบ: `ออเดอร์` + เลข + ชื่อช่อง + ค่าใหม่

| ช่อง | พิมพ์ |
|---|---|
| ผู้สั่ง | `ออเดอร์ 3 ผู้สั่ง คุณเอ` |
| ช่องทาง | `ออเดอร์ 3 ช่องทาง Line` |
| ราคา | `ออเดอร์ 3 ราคา 2900` |
| แบบโบว์ | `ออเดอร์ 3 แบบ ML` |
| รายละเอียด | `ออเดอร์ 3 รายละเอียด แดงทอง` |
| วันที่ | `ออเดอร์ 3 วันที่ 12/11` |
| ค่าจ้างทำ | `ออเดอร์ 3 ค่าจ้าง 150` |

- หลายช่องในข้อความเดียว: `ออเดอร์ 3 ผู้สั่ง คุณเอ ช่องทาง Line ราคา 2900`
- หลายชิ้นพร้อมกัน: `ออเดอร์ 1-10 ค่าจ้าง 150` หรือ `ออเดอร์ 2 5 8 ราคา 2900`
- ลบค่าในช่อง ใส่ `-`: `ออเดอร์ 3 ผู้สั่ง -`
- ชื่อช่องต้องมีเว้นวรรคคั่นหน้าและหลัง
- บอทตอบสั้นๆ ว่าแก้อะไร ไม่ส่งลิงก์ตารางกลับมา

## ติ๊กจ่าย

| พิมพ์ | ผล |
|---|---|
| `ออเดอร์ 3 จ่ายแล้ว` | ลูกค้าจ่ายค่าโบว์ |
| `ออเดอร์ 3 ยังไม่จ่าย` | เอาติ๊กลูกค้าออก |
| `ออเดอร์ 3 จ่ายค่าจ้างแล้ว` | จ่ายค่าจ้างช่าง |
| `ออเดอร์ 3 ยังไม่จ่ายค่าจ้าง` | เอาติ๊กค่าจ้างออก |

ไม่มีคำว่า "ค่าจ้าง" = ลูกค้าจ่าย ยกเว้น `ค่าจ้าง 150 จ่ายแล้ว` ที่หมายถึงจ่ายค่าจ้าง

## เรียกดู

| พิมพ์ | ได้ |
|---|---|
| `ตารางออเดอร์` | ยอดสรุปเดือนนี้ + ลิงก์ตาราง A4 (พิมพ์หรือบันทึก PDF ได้จากในหน้า) |
| `ตารางออเดอร์ เดือน 10` | ของเดือนอื่น |
| `ออเดอร์ 3` | ชิ้นเดียว ทุกช่อง |
| `ออเดอร์ ว่าง` | ชิ้นที่ยังไม่มีผู้สั่ง |
| `ออเดอร์ ยังไม่จ่าย` | มีผู้สั่งแล้ว ลูกค้ายังไม่จ่าย |
| `ออเดอร์ ค้างค่าจ้าง` | ยังไม่จ่ายช่าง |
| `ออเดอร์ แบบ ML` | เฉพาะแบบนั้น |
| `ออเดอร์ ผู้สั่ง คุณเอ` | เฉพาะลูกค้าคนนั้น |
| `ออเดอร์ ช่องทาง Line` | เฉพาะช่องทางนั้น |

ต่อท้าย `เดือน 10` ได้ทุกคำสั่งเรียกดู ไม่ใส่คือเดือนนี้ รายชิ้นแสดงไม่เกิน 30 บรรทัด

## ลบ

`ลบออเดอร์ 3` แล้วพิมพ์ `ยืนยัน` (ยกเลิก ไม่ลบแถว ประวัติยังอยู่)
