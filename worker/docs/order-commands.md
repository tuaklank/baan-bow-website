# คำสั่งรายการโบว์ทางไลน์

คำสั่งในหน้านี้เป็นแพตเทิร์นตายตัว บอทอ่านจากข้อความตรงๆ ไม่ผ่าน AI
ผลจึงเหมือนเดิมทุกครั้งและไม่เสียโทเค็น ตัวอ่านอยู่ที่ `src/order-text.js`
พิมพ์ `วิธีสั่งรายการ` ในไลน์เพื่อดูฉบับย่อ

ข้อความที่ไม่เข้าแพตเทิร์น (เช่น `รายการ 3 สีแดงทอง`) ยังส่งต่อให้ AI อ่านตามเดิม
แต่ AI อาจเดาช่องผิด จึงควรใช้แพตเทิร์นด้านล่าง

## จดใหม่ (ผ่าน AI)

| พิมพ์ | ผล |
|---|---|
| `สั่งโบว์ ML แดงทอง 10 ชิ้น` | ได้ 10 แถว ช่องทางและผู้สั่งว่างไว้ |
| `สั่งโบว์ ML 10 ชิ้น mini 5 ชิ้น` | หลายแบบในข้อความเดียว |

## แก้ไข

รูปแบบ: `รายการ` + เลข + ชื่อช่อง + ค่าใหม่

| ช่อง | พิมพ์ |
|---|---|
| ผู้สั่ง | `รายการ 3 ผู้สั่ง คุณเอ` |
| ช่องทาง | `รายการ 3 ช่องทาง Line` |
| ราคา | `รายการ 3 ราคา 2900` |
| แบบโบว์ | `รายการ 3 แบบ ML` |
| รายละเอียด | `รายการ 3 รายละเอียด แดงทอง` |
| วันที่ | `รายการ 3 วันที่ 12/11` |
| ค่าจ้างทำ | `รายการ 3 ค่าจ้าง 150` |

- หลายช่องในข้อความเดียว: `รายการ 3 ผู้สั่ง คุณเอ ช่องทาง Line ราคา 2900`
- หลายชิ้นพร้อมกัน: `รายการ 1-10 ค่าจ้าง 150` หรือ `รายการ 2 5 8 ราคา 2900`
- ลบค่าในช่อง ใส่ `-`: `รายการ 3 ผู้สั่ง -`
- ชื่อช่องต้องมีเว้นวรรคคั่นหน้าและหลัง
- บอทตอบสั้นๆ ว่าแก้อะไร ไม่ส่งลิงก์ตารางกลับมา

## ติ๊กจ่าย

| พิมพ์ | ผล |
|---|---|
| `รายการ 3 จ่ายแล้ว` | ลูกค้าจ่ายค่าโบว์ |
| `รายการ 3 ยังไม่จ่าย` | เอาติ๊กลูกค้าออก |
| `รายการ 3 จ่ายค่าจ้างแล้ว` | จ่ายค่าจ้างช่าง |
| `รายการ 3 ยังไม่จ่ายค่าจ้าง` | เอาติ๊กค่าจ้างออก |

ไม่มีคำว่า "ค่าจ้าง" = ลูกค้าจ่าย ยกเว้น `ค่าจ้าง 150 จ่ายแล้ว` ที่หมายถึงจ่ายค่าจ้าง

## เรียกดู

| พิมพ์ | ได้ |
|---|---|
| `ตารางรายการ` | ยอดสรุปเดือนนี้ + ลิงก์ตาราง A4 (พิมพ์หรือบันทึก PDF ได้จากในหน้า) |
| `ตารางรายการ เดือน 10` | ของเดือนอื่น |
| `รายการ 3` | ชิ้นเดียว ทุกช่อง |
| `รายการ ว่าง` | ชิ้นที่ยังไม่มีผู้สั่ง |
| `รายการ ยังไม่จ่าย` | มีผู้สั่งแล้ว ลูกค้ายังไม่จ่าย |
| `รายการ ค้างค่าจ้าง` | ยังไม่จ่ายช่าง |
| `รายการ แบบ ML` | เฉพาะแบบนั้น |
| `รายการ ผู้สั่ง คุณเอ` | เฉพาะลูกค้าคนนั้น |
| `รายการ ช่องทาง Line` | เฉพาะช่องทางนั้น |

ต่อท้าย `เดือน 10` ได้ทุกคำสั่งเรียกดู ไม่ใส่คือเดือนนี้ รายชิ้นแสดงไม่เกิน 30 บรรทัด

## ลบ

ทุกคำสั่งลบต้องพิมพ์ `ยืนยัน` ต่อ (ยกเลิก ไม่ลบแถว ประวัติยังอยู่)

| พิมพ์ | ผล |
|---|---|
| `ลบรายการ 3` | ลบชิ้นเดียว |
| `ลบรายการ 9-23` | ลบทั้งช่วง |
| `ลบรายการ 2 5 8` | ลบทีละเลข |

## เลขรายการ

เลขรายการคือลำดับในสมุด ช่องแรกของตาราง พิมพ์ `ออเดอร์` แทน `รายการ` ก็ได้ ผลเหมือนกัน

- **จดใหม่เติมเลขที่ว่างก่อน** ลบรายการ 6 ไปแล้ว `สั่งโบว์ ...` ครั้งถัดไปจะได้เลข 6 ไม่ใช่เลขต่อท้าย
  สั่งหลายชิ้นก็เติมเลขว่างจากน้อยไปมากจนหมด แล้วจึงต่อท้าย
- **จดลงเลขที่ต้องการเอง** `รายการ 6 แบบ ML รายละเอียด แดงทอง ราคา 3000`
  ใช้ได้กับเลขที่ว่าง (ลบไปแล้ว) และเลขถัดไปต่อท้าย ต้องบอกแบบโบว์ทุกครั้ง
- **เลขที่ข้ามไปจดไม่ได้** มี 10 รายการแล้วพิมพ์ `รายการ 30 ...` บอทจะบอกว่าเลขถัดไปคือ 11
- **จดทับเลขที่ลบไว้ = เริ่มใหม่ทั้งแถว** ชื่อผู้สั่งและติ๊กจ่ายของเดิมไม่ค้างมา ของเดิมดูได้ในประวัติ
- **เลขหลังคำว่า "รายการ" คือเลขรายการเสมอ** ไม่ใช่จำนวนชิ้น จำนวนชิ้นต้องมีคำว่า "ชิ้น"
- เลขนับต่อเนื่องทุกเดือน ไม่เริ่ม 1 ใหม่ตอนขึ้นเดือน

## ย้อนกลับ / เดินหน้า

| พิมพ์ | ผล |
|---|---|
| `ย้อนกลับ` | ย้อนคำสั่งรายการล่าสุดหนึ่งคำสั่ง พิมพ์ซ้ำ = ย้อนอีกหนึ่งคำสั่ง |
| `เดินหน้า` | ทำคำสั่งที่เพิ่งย้อนไปกลับมา ทีละคำสั่ง จนถึงจุดล่าสุด |

ไม่ต้องยืนยันทั้งสองคำสั่ง บอทตอบทุกครั้งว่าย้อนอะไรไป และครั้งถัดไปจะย้อนอะไร

| คำสั่งที่ถูกย้อน | ผล |
|---|---|
| จดรายการ | แถวที่จดมาหายจากตาราง เดินหน้าแล้วได้เลขเดิมกลับมา |
| แก้ไข / ติ๊กจ่าย | ทุกช่องกลับเป็นค่าเดิม |
| ลบ | รายการที่ลบกลับมา |

- หนึ่งขั้น = หนึ่งข้อความคำสั่ง ไม่ว่าจะแตะกี่ชิ้น (`รายการ 1-10 ค่าจ้าง 150` = หนึ่งขั้น)
- ย้อนได้ลึกสุด 20 คำสั่งล่าสุด
- สั่งคำสั่งรายการใหม่หลังย้อนกลับ จะเดินหน้าไปทางเดิมไม่ได้อีก
- คำสั่งเรียกดูไม่นับเป็นขั้น
- ใช้กับรายการโบว์เท่านั้น ไม่ย้อนเอกสาร งาน สต๊อก หรือรายจ่าย
- คำสั่งที่สั่งไว้ก่อนเปิดใช้ระบบนี้ย้อนไม่ได้
